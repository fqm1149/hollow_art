# 🌳 Hollow Art - 树洞重绘 v1.0.0

北大树洞全新前端，基于 Treehole Parser API 的 Chrome 扩展。

## ✅ 功能一览

### 首页
| 功能 | 说明 |
|------|------|
| 瀑布流/单栏切换 | 3栏瀑布流 或 单栏列表 |
| 栏数调节 | 1-5栏滑块，LocalStorage 记忆 |
| 三Tab切换 | 最新 / 关注 / 悬赏 |
| 无限滚动 | IntersectionObserver 自动加载 |
| 开屏自动加载 | 启动时加载3页 |
| 图片懒加载 | 并行加载，性能优化 |
| 搜索 | Enter 触发，空搜索回首页 |
| 入场动画 | 卡片渐入 + 缩放反馈 |

### 帖子详情
| 功能 | 说明 |
|------|------|
| 双栏布局 | 左侧内容+元数据，右侧评论 |
| 评论瀑布流 | 1-4栏可调，Grid布局 |
| 评论滚动加载 | 到底自动加载下一页 |
| 图片灯箱 | 点击查看原图 |
| 全屏按钮 | 内容区全屏查看 |
| 评论ID显示 | 便于构建回复关系 |
| 楼主标识 | 楼主评论绿色边框 |
| 评论拓扑视图 | 时间/拓扑切换，连串回复扁平化 |
| 帖号引用检测 | #+7位数字自动识别 |
| 引用悬停预览 | 鼠标悬停300ms显示帖子预览浮窗 |
| 引用点击跳转 | 点击引用跳转到目标帖子 |
| 帖子栈导航 | 引用跳转支持栈式返回 |

### 外观
| 功能 | 说明 |
|------|------|
| 暗色模式 | 一键切换，CSS变量主题 |
| 主题色 | 颜色选择器，实时生效 |
| 字体优化 | 正文15px，评论14px |
| 响应式 | 小屏自动单栏 |

## 📦 安装

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹

## 📁 文件

```
hollow_art/
├── manifest.json     # Chrome 扩展配置 v1.0.0
├── parser.js         # Treehole Parser v7.1
├── app.js            # 前端逻辑
├── popup.html        # 扩展弹窗
├── icons/
└── README.md
```

## 🔧 依赖

- **Treehole Parser** v7.1+（included）
- 浏览器已登录树洞
